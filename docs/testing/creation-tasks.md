## 桌面人工验收

1. 输入内容后观察保存中/已自动保存；重开任务并编辑，确认仍只有一张卡片。故意使保存失败后检查内容保留、错误原因和重试入口。
2. 规划两张，修订计划两次；切换模式或修改输入后确认旧计划不能直接执行。查看历史版本后重新规划并确认。
3. 第一张保存后停止、继续或仅重试失败图片，确认成功位置不重画；保存失败时确认只重试已有图片。
4. 完成后检查输入不可编辑；以此新建后重新规划，确认旧结果、计划和任务保留。
5. 用历史数据副本检查同一草稿的多次执行均显示其关联输入；检查长图完整预览、放大、导出和对应图库跳转。

自动测试使用模拟 IPC 和假 CLI，不调用付费模型。真实模型生图及原生导出对话框需在已登录的桌面用户会话验收。
